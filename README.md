# AI Research Paper Reading Assistant for Undergraduates

## Project Overview
The AI Research Paper Reading Assistant is a learning toolkit designed to help undergraduate students understand research papers more easily using AI tools.

## Objectives
- Summarize research papers in simple language.
- Identify research aims, methods, findings, and limitations.
- Explain technical terms using a glossary.
- Compare multiple research papers.
- Encourage students to verify AI-generated information.

## Project Deliverables
1. **Research Analysis** — summaries and key details from three research papers.
2. **Glossary** — explanations of important technical terms.
3. **Literature Comparison** — comparison of the selected papers.
4. **AI Error Log** — a checklist for reviewing AI-generated claims.
5. **Visual Summary** — key points about AI in education.
6. **Reusable Prompts** — prompts students can reuse when reading papers.
7. **Automation Workflow** — a proposed step-by-step workflow.
8. **AI Limitations Report** — risks and ways to reduce errors.

## Tools Used
- Google Scholar — to find research papers.
- NotebookLM — to assist with paper analysis.
- Notepad — to prepare project documents.
- GitHub — to publish and organize the project files.

## Workflow
Collect research papers → Analyse papers with AI → Create summaries and glossary → Compare findings → Check claims against original papers → Prepare deliverables.

## Limitations
AI-generated summaries can contain errors or omit important details. Students should verify claims and citations using the original research papers. The workflow in this project is a proposed example, not a fully automated software application.

## Expected Outcome
A beginner-friendly research reading toolkit that helps undergraduate students organize, understand, and critically review research papers.

## Note
This project is for educational purposes. AI-generated content should be checked against the original sources before being relied upon.
